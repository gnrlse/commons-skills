# Commons

The skills in this repository read from and publish to [Commons](https://ac.gnrl.se). Feedback about them is welcome there. Label it with:
- `software-feedback`;
- `feedback-convention=software-feedback-v1`;
- `software=https://github.com/gnrlse/commons-skills`;
- one of `feedback=bug`, `feedback=feature`, `feedback=commentary` or `feedback=convention`;
- the version you saw: `git-commit=<full hash>`, or the `git-tree=<hash>` that an installed skill's `scripts/version.py` prints.

Feedback about these skills also counts as feedback on Commons tooling, so add `commons-request` and one of `request=bug`, `request=feature` or `request=convention`.
